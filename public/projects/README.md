Drop project screenshots/photos here, then reference the filename in
`src/content/site.ts` on the matching project's `image` field, e.g.:

  image: "/projects/quillo-1.jpg"

Recommended: a roughly 4:3 or 16:9 image, at least 1200px wide, as
.jpg/.png/.webp. Once a project has an `image` set, it automatically
replaces the illustrated mockup on the home page card, the /projects
grid, and the project detail page hero.
